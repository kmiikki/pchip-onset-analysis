# Examples

This directory contains example datasets and generated workflow outputs.

## Synthetic RGB-TR example

See:

```text
synthetic-rgb-tr/
```

This example contains a synthetic `rgb-tr.csv` input file and generated output
from the PCHIP onset workflow.

The synthetic data are demonstration data only. They are not experimental
results and must not be used for scientific conclusions.

The main example files are:

```text
synthetic-rgb-tr/rgb-tr.csv
synthetic-rgb-tr/rgb-tr-sg.csv
synthetic-rgb-tr/pchip/
```

The script used to create the synthetic RGB-TR demonstration input is kept
separately from the compact analysis example:

```text
examples/scripts/make-synthetic-rgb-tr.py
```

For details, see:

```text
synthetic-rgb-tr/README.md
```
